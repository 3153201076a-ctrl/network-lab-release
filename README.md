## 下载

最新版本：**v2.2.2**

前往 [Releases](../../releases/latest) 下载 `网络实训平台-2.2.2-Setup.exe`。

## 安装

1. 运行安装包；
2. 首次运行若 Windows 提示「已保护你的电脑」，点【更多信息 → 仍要运行】即可（软件未做代码签名，属正常提示）；
3. 安装后从开始菜单或桌面快捷方式启动，打开即为独立窗口。

## 更新

客户端的「设置 → 更新 → 检查更新」会读取本仓库根目录的 `update-manifest.json`。
国内网络访问 GitHub 不稳定时，会走 jsDelivr 镜像；都连不上时可点「手动下载」。
